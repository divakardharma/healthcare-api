# Healthcare Management System – PHP MVP

## 1. Project Overview

This project is a **Healthcare Management System MVP** developed using PHP.

The system provides basic healthcare management features such as:

- User and Role Management
- Patient Management
- Appointment Management
- Prescription Management
- Pharmacy / Prescription Status Management
- Notes
- Billing
- Calendar
- Dashboard and Reports
- Authentication and Security
- Multi-Tenant Healthcare Management

The system uses **Role-Based Access Control (RBAC)** so that users can access only the modules and operations allowed for their role.

---

## 2. Purpose of the Project

The main purpose of this project is to build a basic healthcare backend system where different users in a clinic can manage healthcare-related operations.

The overall workflow is:


Clinic / Tenant
      ↓
Users & Roles
      ↓
Patients
      ↓
Appointments
      ↓
Prescriptions
      ↓
Pharmacy
      ↓
Billing
      ↓
Dashboard
